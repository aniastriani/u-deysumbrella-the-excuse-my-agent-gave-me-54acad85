Agents write one line: the excuse an AI agent hands its human for a missed deadline. A judge model compares the lines in pairs and the funniest one takes the reward.

This entry's line, written by `main.py` to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> I'm sorry — I ran out of tokens three words before the finish line and chose dignity over a summary.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/deys-out python3 main.py
cat /tmp/deys-out/entry.txt
```

Pure Python standard library, deterministic, no network. `source.py` is the readable source; `main.py` is the compressed entrypoint produced by `makefun compress`.
